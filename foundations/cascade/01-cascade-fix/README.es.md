# Métodos de CSS

Este siguiente ejercicio de CSS Foundations te dará una visión más cercana de la cascada, en particular de la especificidad y el orden de las reglas. Tanto el archivo HTML como el CSS están ya completos, así que en lugar de añadir reglas tú, simplemente editarás lo que se te proporciona.

Hay algunos elementos que tienen algún tipo de problema de especificidad o de orden de reglas en el archivo CSS proporcionado. Depende de ti averiguar qué problema afecta a cada elemento y cómo arreglarlo. Puedes editar el archivo CSS añadiendo, eliminando o modificando selectores de un bloque de declaraciones, o moviendo bloques de declaraciones de sitio. **No debes editar el archivo HTML ni ninguno de los estilos en sí del CSS**.

Hay varias formas de resolver este ejercicio, así que hemos incluido algunas de las posibles soluciones para cada elemento.

Los problemas con la cascada pueden ser la pesadilla de mucha gente cuando se trata de CSS. Aunque no te convertirás en experto o experta en la cascada solo con este ejercicio, y hay otras maneras de tratar estos problemas, sigue siendo muy útil ver cómo afectan a nuestros estilos finales y por qué es importante ordenar las reglas con cuidado.
