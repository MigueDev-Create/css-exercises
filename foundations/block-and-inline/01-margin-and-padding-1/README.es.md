# Práctica de margin y padding

Para este primer ejercicio, simplemente edita el archivo `style.css` para que los divs se vean como en la imagen de abajo. Edita el CSS solo donde se te indique en el archivo. Solo deberías tener que cambiar los valores de margin y padding en este ejercicio. No deberías tener que añadir ni eliminar propiedades en el CSS, ni tocar el HTML.

### Autocomprobación
Usa esta sección para revisar tu trabajo. En _estos_ proyectos, tu objetivo no es alcanzar una perfección de píxel al 100%, sino usar las herramientas que has aprendido para acercarte razonablemente al resultado deseado.

- Div One y Div Three tienen 32px entre su texto y su borde.
- Div One tiene 12px entre él y cualquier otro elemento de la página.
- Hay un hueco de 48px entre Div Two y Div Three.
- Div Three está alineado a la derecha.
- La alineación de Div Three se consigue usando `margin` (y no float, flexbox, etc.).
