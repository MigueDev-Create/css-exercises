# Combinador de descendencia
Entender cómo funcionan los combinadores se vuelve mucho más fácil cuando empiezas a jugar con ellos y ves qué se ve afectado exactamente por ellos y qué no.

El objetivo de este ejercicio es aplicar estilos a elementos que son descendientes de otro elemento, dejando sin estilo los elementos que *no* son descendientes de ese elemento.

Puedes usar selectores de tipo o de clase en este ejercicio; usa aquel con el que sientas que quieres practicar más. El archivo HTML está preparado (así que no hace falta editar nada en él) de modo que funcione cualquier combinación de selectores, así que si te sientes con ganas de aventura, puedes incluso probar a combinar un selector de tipo *y* de clase para el combinador de descendencia.

Las propiedades que debes añadir son:

* Solo los elementos `p` que sean descendientes del elemento `div` deben tener fondo amarillo, texto rojo, un tamaño de fuente de 20px y alineación centrada.
