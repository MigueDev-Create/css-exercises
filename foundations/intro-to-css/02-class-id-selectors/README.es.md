# Selectores de clase e ID
Saber cómo añadir atributos class e ID a los elementos HTML, así como usar sus respectivos selectores, es valiosísimo. Es importante practicarlo.

En el archivo HTML proporcionado hay varios elementos a los que tendrás que añadir atributos class o ID, como se indica en la imagen del resultado más abajo. Después tendrás que añadir reglas en el archivo CSS proporcionado usando la sintaxis de selector correcta. Observa la imagen del resultado con atención e intenta tener en cuenta qué elementos parecen tener un estilo similar (clases), cuáles pueden ser completamente únicos respecto al resto (ID) y cuáles tienen pequeñas variaciones respecto a otros (varias clases).

No es del todo importante qué valores de clase o ID uses, ya que aquí lo importante es ser capaz de añadir los atributos y usar la sintaxis de selector correcta para dar estilo a los elementos. Para los colores de este ejercicio, prueba a usar un valor que no sea una palabra clave (RGB, HEX o HSL). Las propiedades que debes añadir a cada elemento son:

* **Todos los elementos impares**: un fondo rojo claro/rosa y una lista de fuentes que contenga `Verdana` y `DejaVu Sans` con `sans-serif` como alternativa
* **El segundo elemento**: texto azul y un tamaño de fuente de 36px
* **El tercer elemento**: además de los estilos de todos los elementos impares, añade un tamaño de fuente de 24px
* **El cuarto elemento**: un fondo verde claro, un tamaño de fuente de 24px y negrita

Consejo rápido: en VS Code puedes cambiar el formato en el que se muestran los colores entre RGB, HEX o HSL pasando el ratón sobre el valor del color en el CSS y haciendo clic en la parte superior del popup que aparece.

> ### Nota:
> Parte de tu tarea consiste en añadir una fuente a _algunos_ de estos elementos. Las fuentes de tu navegador pueden ser distintas a las que se muestran en la imagen del resultado deseado. Mientras confirmes que las fuentes _se están_ aplicando a las líneas correctas, cualquier diferencia está bien para este ejercicio.
