# Métodos para añadir CSS
En este ejercicio vas a practicar cómo añadir CSS a un archivo HTML usando los tres métodos: CSS externo, CSS interno y CSS en línea. En este ejercicio solo debes usar selectores de tipo al añadir estilos mediante los métodos externo e interno. También debes usar palabras clave para los colores (p. ej. "blue") en lugar de valores RGB o HEX.

Hay tres elementos a los que debes añadir estilos, cada uno con un método distinto de añadir CSS, como se indica en la imagen del resultado más abajo. Todos los demás ejercicios de esta sección tendrán un archivo CSS ya creado y enlazado por ti, pero en este ejercicio tendrás que crear el archivo y enlazarlo tú en el HTML. Se trata de practicar estos distintos métodos y de acertar con la sintaxis.

> ## Consejo rápido:
> No te preocupes por detalles de estos ejercicios que no se mencionen específicamente en el enunciado o en la sección de autocomprobación. Como los resultados deseados son capturas de pantalla, tu navegador puede mostrar una fuente distinta, los colores pueden verse diferentes en tu equipo o el espaciado entre elementos puede parecer distinto. Céntrate solo en los aspectos concretos que se supone que estás aprendiendo en cada ejercicio.

Las propiedades que debes añadir a cada elemento son:

* `div`: fondo rojo, texto blanco, tamaño de fuente de 32px, alineado al centro y en negrita
* `p`: fondo verde, texto blanco y tamaño de fuente de 18px
* `button`: fondo naranja y tamaño de fuente de 18px
