# Agrupar selectores

Vamos a construir un poco sobre el ejercicio anterior. Aquí vas a dar a dos elementos un nombre de clase único a cada uno, y después añadirás reglas para los estilos que ambos comparten, así como para sus estilos propios. Fíjate bien en la imagen del resultado de abajo para ver exactamente qué tiene de único cada elemento y qué tienen en común ambos.

Esto te ayudará a seguir practicando cómo añadir clases y usar selectores de clase, así que asegúrate de añadir el atributo class en el archivo HTML. Para el resto de estos ejercicios, el formato de los colores queda enteramente en tus manos; ¡confiamos en que practicarás con los distintos valores! Las propiedades que debes añadir a cada elemento son:

- **El primer elemento**: fondo negro y texto blanco
- **El segundo elemento**: fondo amarillo
- **Ambos elementos**: un tamaño de fuente de 28px y una lista de fuentes que contenga `Helvetica` y `Times New Roman`, con `sans-serif` como alternativa
