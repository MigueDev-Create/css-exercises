# Otro estilo de cabecera habitual

Estamos empezando a colar un poco más de CSS que aún no has visto. No te preocupes por eso de momento; solo queremos que las cosas se vean un poco más bonitas, y ese CSS no interferirá con tu tarea.

Para este ejercicio probablemente necesites editar un poco el HTML. A menudo, con flexbox necesitas añadir contenedores alrededor de las cosas para que vayan donde necesitas. En este caso, seguramente quieras separar los elementos que van a la izquierda y a la derecha de la cabecera.

Igual que hiciste en el ejercicio `02-flex-header`, vas a anidar contenedores flex unos dentro de otros.

## Resultado deseado
Como en el ejemplo anterior, este necesita ser flexible en el centro, con los elementos empujados a izquierda y derecha.
