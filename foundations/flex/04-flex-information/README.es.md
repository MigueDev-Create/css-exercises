# Una característica muy común en sitios web

El objetivo de este ejercicio es recrear una sección que se encuentra en muchos sitios web informativos.

Para este también vas a necesitar editar un poco el HTML. No podemos ponértelo _demasiado_ fácil. Querrás añadir contenedores alrededor de los distintos elementos para poder aplicarles flex. ¡Suerte!

### Autocomprobación

- Todos los elementos están centrados en la página (horizontalmente, no verticalmente).
- El título está centrado en la página.
- Hay 32px entre el título y los 'items'.
- Hay 52px entre cada item.
- Los items están dispuestos horizontalmente en la página.
- Los items miden solo 200px de ancho y el texto se ajusta en varias líneas.
- El texto de los items está centrado.
