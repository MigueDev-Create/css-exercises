# El Holy Grail Layout con Grid

Ahora es el momento de practicar las herramientas de Grid que hemos aprendido y crear una maquetación que quizá te resulte familiar. Vamos a hacer un Holy Grail Layout como los que creamos usando Flexbox. La diferencia aquí es que no vamos a apoyarnos en Flexbox para este ejercicio. Usaremos solo Grid. ¡Podrás comprobar por ti mismo las ventajas de Grid!

### Pistas

- Solo necesitas añadir a los selectores CSS
- Vuelve a la lección de Creating a Grid si no recuerdas cómo convertir un elemento en una cuadrícula
- Usa tamaños de pista fijos (p. ej. píxeles) para tus columnas y filas

### Autocomprobación

- El gap es de 15px
- La cuadrícula tiene dos columnas
- La cuadrícula tiene cuatro filas
- La segunda columna es tres veces más grande que la primera
- La tercera fila es cinco veces más grande que las demás
- Los elementos header y footer abarcan ambas columnas
- El elemento sidebar abarca solo la primera columna
- Los elementos nav y article abarcan la segunda columna
