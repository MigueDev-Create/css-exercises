# Holy Grail Layout responsive con Grid

En este ejercicio vamos a coger nuestro Holy Grail Layout del primer ejercicio y a hacerlo responsive. Para ello simplemente cambiaremos los tamaños fijos de las pistas (tracks) por tamaños dinámicos. Considéralo un calentamiento para el siguiente ejercicio y asegúrate de que tu maquetación responde correctamente al redimensionar la ventana del navegador.

### Pistas
- Solo necesitas añadir a los selectores CSS
- Usa tamaños de pista dinámicos para tus columnas y filas

### Autocomprobación
- El gap es de 15px
- La cuadrícula tiene dos columnas
- La cuadrícula tiene cuatro filas
- Las pistas de la cuadrícula no usan tamaños estáticos (¡nada de píxeles!)
- La segunda columna es tres veces más grande que la otra
- La tercera fila es cinco veces más grande que las demás
- Las columnas se estrechan y se ensanchan a medida que cambia el tamaño del viewport
- La fila 3 se hace más alta para dar cabida al texto que se ajusta en varias líneas cuando estrechas el viewport
