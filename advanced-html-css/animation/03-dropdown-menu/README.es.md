# Dropdown Menu

En este ejercicio hemos preparado un menú desplegable. Carga la página: verás un único título de menú, con un desplegable que se abre al hacer clic en el título.

Tu tarea es añadir una animación al menú desplegable para que tenga un efecto de expansión. Mira el resultado deseado más abajo y fíjate en la ilusión de _rebote_ cuando el desplegable se expande cerca de su estado final.

### Pistas
- Necesitas especificar una propiedad _transform-origin_ para que el menú desplegable empiece a transformarse desde arriba
- Necesitas añadir un paso intermedio en la regla keyframe para lograr la ilusión de _rebote_.
