# Ejercicios de CSS

Estos ejercicios consisten en una serie de tareas relacionadas con CSS pensadas para complementar el contenido de HTML y CSS de The Odin Project (TOP). Solo deberías completarlos cuando el currículo te lo indique.

Al hacer estos ejercicios, usa toda la documentación y los recursos que necesites para resolverlos. _No_ se espera que a estas alturas tengas nada de esto memorizado. Consulta la documentación, usa Google y haz lo que haga falta (salvo mirar las soluciones) para completarlos.

> [!IMPORTANT]
> Te animamos a practicar tus habilidades con git haciendo commit de tus cambios y subiéndolos a tu propio fork. Sin embargo, por favor **NO** abras un Pull Request para que tus soluciones se fusionen en este repositorio ni para mostrar tu solución. Si fusionáramos tus cambios, los ejercicios dejarían de estar disponibles como se pretende para las personas que empiezan, y abrir un PR solo nos genera trabajo adicional, ya que tenemos que cerrarlo sin fusionarlo.

## Cómo usar estos ejercicios

1. Haz un fork de este repositorio.
   - Un *fork* es tu propia copia de un repositorio almacenada en tu cuenta de GitHub. Para aprender a hacer un fork, consulta la documentación de GitHub sobre [cómo hacer un fork de un repositorio](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo#forking-a-repository).
1. Clona tu repositorio *forkeado*.
   - Un *clon* es una copia de un repositorio en tu máquina local. Si necesitas ayuda para clonarlo en tu entorno local, puedes aprender cómo hacerlo en la documentación de GitHub sobre [clonar un repositorio](https://docs.github.com/en/github/creating-cloning-and-archiving-repositories/cloning-a-repository-from-github/cloning-a-repository).
1. Ve al directorio de un ejercicio y abre el archivo HTML en un navegador. Puedes abrir el archivo directamente o usar algo como la extensión Live Preview de VSCode.
1. En cada ejercicio, lee el README a fondo antes de empezar a trabajar.
    - Cada README tiene una lista de "Autocomprobación". Úsala como una lista de **requisitos** para asegurarte de que tu solución coincide con la imagen del "Resultado deseado".
1. Haz tus modificaciones en los archivos `index.html` y/o `style.css` para que el resultado en tu navegador se parezca a la(s) imagen(es) del resultado deseado.
    - Según las instrucciones del ejercicio, puede que solo necesites editar uno de estos archivos.
1. Una vez que termines con éxito un ejercicio, mira la solución de ejemplo de TOP.
    - ¡No deberías mirar la solución de un ejercicio hasta haberlo terminado!
    - Si tu solución difiere de la de TOP (y aun así cumple los requisitos del ejercicio), es perfectamente válido. La solución proporcionada es solo un ejemplo y siempre hay varios enfoques posibles. No dudes en preguntar en nuestro Discord si hay partes de la solución de ejemplo que no entiendes.

> [!IMPORTANT]
> No envíes tus soluciones a este repositorio: cualquier PR que lo haga se cerrará sin fusionarse.

## Algunas pistas

- Las soluciones de ejemplo colocan todos los cambios al _final_ del archivo CSS, lo que puede duplicar algunos selectores (por ejemplo, puede haber un `body {}` en el CSS proporcionado y otro `body {}` en la solución). Cuando trabajes en un ejercicio, la buena práctica es añadir tu CSS a los selectores existentes en lugar de duplicarlos al final del archivo. Sacrificamos esta buena práctica en nuestras soluciones oficiales para que quede especialmente claro qué cosas cambiamos para resolver el ejercicio.
- Salvo que se indique en la sección de autocomprobación, no te preocupes por acertar el valor exacto en píxeles de cosas como el margin, el padding o el tamaño de fuente. Estos ejercicios pretenden poner a prueba tus conocimientos de CSS, no tu capacidad de adivinar que una captura de pantalla usa `font: sans-serif bold 16px` o que el margen es _exactamente_ `42px`.
- Puede que necesites añadir algunos elementos a tu HTML para colocar las cosas en el sitio correcto. (En los primeros ejercicios lo indicamos explícitamente cuando hace falta.)
- Puede que necesites añadir más selectores a tu archivo CSS. Los primeros ejercicios tienen casi todo hecho por ti, pero a medida que avances verás que necesitas añadir cada vez más selectores para obtener el resultado correcto.
